# File Structure / 文件结构

公开版目录：

```text
chuo-content-os/
  00-项目入口-entry/
  01-产品本体-product-core/
  02-市场与竞品-market-research/
  03-内容与销售-content-sales/
  04-创作流水线-creation-pipeline/
  05-校准与复盘-calibration-retro/
  06-系统引擎-system-engine/
  99-原始资料-raw-materials/
```

## 各层职责

| 层级 | 职责 | 公开版内容 |
|---|---|---|
| 00 | 入口、指南、看板 | 操作指南和说明 |
| 01 | 产品本体 | 空模板 |
| 02 | 市场竞品 | 空模板 |
| 03 | 内容销售 | 平台模板 |
| 04 | 创作流水线 | 虚构样例和说明 |
| 05 | 校准复盘 | rubric、预测、复盘模板 |
| 06 | 系统引擎 | CLI、模板、schema |
| 99 | 原始资料 | 只放说明 |

## 私有项目

CLI 初始化出的私有项目使用同样结构。区别是私有项目里可以放真实内容，而公开仓库只能放模板和虚构样例。
