# Privacy Model / 隐私与开源边界

这个仓库的原则是：**公开系统结构，不公开内容资产**。

## 可以公开

- 目录结构
- 操作指南
- 空白模板
- 通用 rubric
- schema
- CLI 工具
- 虚构示例

## 必须私有

- 真实稿件、文章、帖子、逐字稿
- 真实发布清单
- 真实播放量、阅读量、点赞、评论、分享
- 真实 URL、账号名、用户评论
- 真实对标账号和竞品拆解
- audience、benchmark、persona 的真实内容
- 真实 rubric 权重和复盘沉淀
- `.env`、cookie、token、session、数据库
- 截图、导出文件、原始素材

## 推荐拆分

```text
公开仓库：chuo-content-os
  只放模板、工具、说明、虚构样例

私有仓库：my-content-project
  放真实内容、真实数据、真实复盘
```

## 不要直接公开现有私有仓库

Git 历史会保留曾经提交过的文件。即使后来删除，公开后仍可能被看到。

安全做法是：

1. 新建干净公开仓库
2. 白名单复制结构和模板
3. 示例全部虚构
4. 扫描敏感内容
5. 先推 private 检查
6. 最后再切 public
