# 00 项目入口

这里是整个内容 OS 的入口层。它回答三个问题：

1. 这个项目现在是什么状态？
2. 下一步该做什么？
3. 新人或未来的自己应该怎么操作？

## 推荐文件

| 文件 | 用途 |
|---|---|
| `操作指南-OPERATION_GUIDE.md` | 从初始化到发布复盘的完整操作说明 |
| `项目结构说明-STRUCTURE.md` | 每一层目录放什么、不放什么 |
| `WORKFLOW.md` | 日常工作流速查 |
| `STATUS.md` | 项目看板模板 |
| `CHANGELOG.md` | 公开骨架的版本变化 |
| `文档-docs/` | 隐私边界、GitHub 发布检查、方法说明 |

## 使用方式

第一次进入项目，先读：

1. `操作指南-OPERATION_GUIDE.md`
2. `项目结构说明-STRUCTURE.md`
3. `WORKFLOW.md`

然后用 `06-系统引擎-system-engine/工具-tools/content_os.py init` 初始化你的私有内容项目。
