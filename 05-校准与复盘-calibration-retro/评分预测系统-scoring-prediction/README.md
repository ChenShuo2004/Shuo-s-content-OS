# 评分预测系统

这一层保存正式预测日志。

## 子目录

| 目录 | 用途 |
|---|---|
| `预测日志-predictions/` | 盲预测日志 |
| `视频评分预测-video-scoring-prediction/` | 视频内容的评分说明 |
| `文章评分预测-article-scoring-prediction/` | 长文内容的评分说明 |
| `帖子评分预测-post-scoring-prediction/` | 短帖内容的评分说明 |

## 预测日志要求

- 写在发布和看数据之前
- 包含 bucket、预测中心、理由、反事实
- 发布后登记平台和 URL
- T+N 后追加复盘
