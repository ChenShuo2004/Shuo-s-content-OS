# 05 校准与复盘

这一层是内容 OS 的判断系统。它负责把“感觉”变成可复盘的预测。

## 核心文件

| 文件/目录 | 用途 |
|---|---|
| `rubric_notes.md` | 当前评分规则 |
| `rubric-memo.md` | 带证据的观察和待升级规则 |
| `audience.md` | 受众画像 |
| `benchmark.md` | 对标与锚点 |
| `script_patterns.md` | 写作模式沉淀 |
| `初始评分表-starter-rubrics/` | 起步 rubric |
| `评分预测系统-scoring-prediction/` | 预测日志与评分说明 |
| `复盘记录-retros/` | 复盘记录副本 |

## 使用纪律

1. 预测必须在看到数据前写。
2. 预测段写完后不改，只追加复盘。
3. 复盘必须引用实际数据。
4. rubric 更新需要多个样本支持。

公开版只放模板。真实 rubric 权重、对标、受众画像和复盘结论都留在私有项目。
