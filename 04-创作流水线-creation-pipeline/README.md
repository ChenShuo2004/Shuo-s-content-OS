# 04 创作流水线

这一层放内容从“想法”到“成品”的过程材料。

## 子目录

| 目录 | 用途 |
|---|---|
| `草稿-scripts/` | 发布前草稿 |
| `样本-samples/` | 虚构示例或脱敏样本 |
| `已拍视频-videos/` | 拍摄/发布后的内容文件夹 |

## 与 05 的关系

- `04` 放内容本体：草稿、样本、成品记录。
- `05` 放判断系统：评分、预测、复盘、rubric。

不要把预测直接写在草稿里。预测日志应该进入 `05-校准与复盘-calibration-retro/评分预测系统-scoring-prediction/预测日志-predictions/`。
