# 03 内容与销售

这一层是平台运营区。每个平台都应该有自己的定位、发布清单、复盘数据、策略素材和资产索引。

## 平台结构

复制 `平台模板-platform-template` 后改名为平台名：

```text
03-内容与销售-content-sales/
  X/
  小红书/
  抖音/
  公众号/
```

每个平台内部保持：

```text
00-平台总览/
01-账号定位/
02-发布清单/
03-复盘数据/
04-策略素材/
05-配图库/
06-视觉资产/
07-对标账号/
08-文章库/
```

## 公开边界

公开版只放模板。真实发布内容、复盘数据、截图、视觉资产、文章全文都不要提交。
